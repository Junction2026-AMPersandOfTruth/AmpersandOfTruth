# WhyFlagged
Answers “why is this here?” on the incident page: the tier, a one-sentence reason, then each signal that fired as an expandable line with its evidence.

- The lead sentence is `Incident.TierReason`. Signal sentences come from the phrasebook and are filled with this incident's numbers.
- The first signal starts open. Each one links to the place in the diff or events that proves it.
- It always ends with the limitation sentence and a link to how levels work.
