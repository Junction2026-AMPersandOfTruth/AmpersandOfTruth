# EditSequence
The story of an incident as a vertical list of member edits: inserted → removed → re-inserted → …, each linking to the exact diff on fi.wikipedia.org.

- Each row shows: the +/− glyph (diff colours plus a symbol), action word, UTC timestamp, `EditorLabel`, the edit summary in EN with the FI original under it, “live N days” for insertions, and a “diff ↗” link to `fi.wikipedia.org/?diff=<rev>&oldid=<parent>`.
- Gaps longer than a month get a quiet row: “… 11 months later”.
- An empty edit summary shows as “(no edit summary)” in muted text, never blank.
