# EditorLabel
How an account appears anywhere in the app: the name exactly as on Wikipedia, linked to its public contributions page. IPs are partially masked.

- Named: a solid initial disc, then the name in `accent`. Anonymous: a dashed “IP” disc, the masked address in mono (`85.76.x.x`), and “(anonymous)”.
- The rule from P0.7: no scores, no adjectives, only observable facts next to it (“12 edits, 9 reverted”).
- Links to `https://fi.wikipedia.org/wiki/Toiminnot:Muokkaukset/<name>`. For IPs, links to the masked range only if we decide to; for now there is no link.
