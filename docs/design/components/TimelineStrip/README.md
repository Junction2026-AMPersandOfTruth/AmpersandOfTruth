# TimelineStrip
All incidents of an investigation on one shared 2003–2026 axis, one lane per article (the top 4–5, then “other”). It is the striking picture above the list.

- Marks reuse the tier shapes: hollow circle, amber diamond, aubergine square. The mark for the hovered card gets an accent ring (`is-hot`).
- Click a mark → scroll to and highlight its card. Drag on the axis → time-range filter.
- The legend is always visible under it. It's a server-rendered SVG, recomputed on filter.
