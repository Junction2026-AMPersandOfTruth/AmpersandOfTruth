# P1.S6 (#33) · Precomputed Editor Behaviour Profiles, IP Prefixes & Coactivity

Precomputes corpus-scoped editor behaviour profiles (`73,437` profiles covering all `862,076` revisions across
`19,742` Finnish Wikipedia articles), IPv4/IPv6 subnet aggregates (`25,514` prefixes), 24-hour same-side revert
coactivity pairs (`163` pairs), and an O(1) `rev_id -> feature vector` lookup (`features.py`, **0.41–0.54 s** for
`500` `rev_id`s), built directly on `research.s1_*` without recomputing reverts.

---

## Files & How to Run

| File | Purpose | Command |
|---|---|---|
| `build.py` | Rebuilds `research.s6_editor_profile`, `s6_ip_prefix`, `s6_coactivity`, `s6_rev_author` sequentially (`max_statement_time = 55`); verifies invariants; writes `results/build_timings.json` | `python3 research/33-s6-editors/build.py` |
| `features.py` | `features_for(rev_ids) -> {rev_id: {...}}` using PK lookups only (zero window functions, zero `corpus.revision` scans; masks usernames/prefixes via `aot.user_display`) | `python3 research/33-s6-editors/features.py --benchmark 500` |
| `report.py` | Computes masked distributions, S1 class mixes, cohort separation tables, masked Top-20 IP prefixes, and coactivity metrics into `results/report_data.json` | `python3 research/33-s6-editors/report.py` |
| `results/build_timings.json` | Per-step wall-clock timings, thresholds, and invariant check counts | Generated by `build.py` |
| `results/report_data.json` | Aggregate, privacy-masked metrics backing every table in this report | Generated by `report.py` |

### Table Schemas & Exact Thresholds

1. **`research.s6_editor_profile`** (`73,437` rows = `73,436` distinct non-null `user` values + `1` synthetic `user = ''` row for the `18` MediaWiki `rev_deleted` revisions; PK `user` `COLLATE utf8mb4_bin`):
   - **Identity & kind:**
     - `kind`: `'named'` (`anonymous = 0, user <> ''`), `'temporary'` (`anonymous = 1 AND user LIKE '~%'` — covers both two-hyphen `~2025-26183-73` and 16 one-hyphen `~2026-10498` temporary accounts, while keeping the single 2017 tilde-prefixed registered account (`anonymous = 0`) in `'named'`), `'ipv4'` (`anonymous = 1` IPv4), `'ipv6'` (`anonymous = 1` IPv6), `'hidden'` (`user IS NULL`, stored as `''` so `aot.user_display("") == "Hidden editor"`).
     - `is_bot`: Reused verbatim from `research.s1_user_stats.is_bot` (`205` bot accounts making `78,190` edits — `prof_ed` §5.4 surgical regex + allowlist, never an edit-volume cutoff).
   - **Activity & concentration:**
     - `first_ts`, `last_ts`, `lifespan_days` (`TIMESTAMPDIFF(SECOND, first_ts, last_ts) / 86400.0`), `edits`, `non_null_edits`, `active_days` (distinct UTC dates), `distinct_pages`.
     - `top_page_id`, `top_page_share` (`max_page_edits / edits`, in `(0, 1]`).
     - `distinct_categories`, `top_category`, `top_category_share` (`max_cat_edits / edits` over `corpus.article_category` `lang = 'fi'`; `NULL` for the `137` profiles whose edits touched only the `457` M-only uncategorised pages), plus `top_tight_category_share` (max category share among categories with `<= 200` corpus pages).
   - **Revert, summary & size behaviour:**
     - `reverted_edits`, `reverted_edits_by_others`, `reverts_made`, `reverts_made_others` (from `s1_user_stats`, plus exact `s1_*` counts for `hidden`).
     - `reverted_ratio = reverted_edits_by_others / edits` (excludes `self_revert`, `bot`, and `excluded` blanking/wide-span collisions so conscientious self-reverts do not inflate an editor's revert rate).
     - `reverts_of_others_ratio = reverts_made_others / edits` (excludes `excluded` and `self_revert`).
     - `summary_usage` (share of edits with non-empty `comment`) and `custom_summary_usage` (share of edits with non-empty text after stripping auto-filled `/* Section */` headers).
     - `median_abs_bytes_delta` (`MEDIAN(|bytes - prev_bytes|)` per editor across page-ordered revisions; page creation uses `prev_bytes = 0`).
   - **Boolean pattern flags (documented thresholds):**
     - **`single_purpose`** (`TINYINT(1)`): `is_bot = 0 AND kind <> 'hidden' AND edits >= 5 AND (top_page_share >= 0.80 OR top_tight_category_share >= 0.80)`, where a **tight category** has `<= 200` corpus articles (`1,419 / 1,428 = 99.4%` of Finnish categories qualify; only `9` umbrella biographical/institutional directories such as `Kansanedustajat` (`2,435` pages) and `Jääkärit` (`665` pages) exceed `200`). Requiring `edits >= 5` avoids the `1/1 = 100%` single-edit tautology.
     - **`throwaway`** (`TINYINT(1)`): `is_bot = 0 AND kind <> 'hidden' AND edits <= 50 AND lifespan_days <= 7.0 AND reverted_ratio > 0.50` (short active span ≤ 7 days, ≤ 50 corpus edits, strictly more than half reverted by other non-bot editors; captures both 1-edit reverted accounts that vanish immediately and short-lived multi-edit accounts).
   - **IP prefix & coactivity links:**
     - `ip_prefix` (`a.b.c.0/24` via `INET_ATON & 0xFFFFFF00` for `ipv4`, canonical 64-bit `...::/64` via `LEFT(INET6_ATON(user), 8)` for `ipv6`, `NULL` for `named`/`temporary`/`hidden`), `ip_prefix_16` (`a.b.0.0/16` for `ipv4`, `NULL` otherwise).
     - `coactivity_partners`, `coactivity_reverted_partners` (partner counts in `s6_coactivity`).

2. **`research.s6_ip_prefix`** (`25,514` rows, PK `ip_prefix`):
   - `prefix_kind` (`'ipv4_24' | 'ipv4_16' | 'ipv6_64'`), `editors`, `edits`, `reverted_edits` (by others), `distinct_pages`, `pages_with_reverted_edits`, `reverted_ratio`, `dispute_war_reverted_edits`, `first_ts`, `last_ts`.

3. **`research.s6_coactivity`** (`163` rows, PK `(user_a, user_b)` with `user_a < user_b` in `utf8mb4_bin`; non-bot, non-hidden accounts):
   - Captures two same-side revert signals on the same `page_id` within `24 h` (`<= 86,400 s`) over non-excluded, non-bot, non-self S1 reverts:
     1. `same_side_reverted`: both `user_a` and `user_b` had edits reverted by the **same revert** `R` (`reverting_rev_id`), with their reverted edits within `24 h`.
     2. `same_side_reverting`: both `user_a` and `user_b` reverted at least one **common target user** `U` (`U <> user_a, user_b`) on `page_id` within `24 h`.
   - Events on `(page_id, user_a, user_b)` are grouped into **24-hour gap episodes** (a new episode starts only after `> 24 h` of inactivity for that pair on that page, preventing a single 20-minute vandal burst with `2 × 2` reverts from quadratically inflating into `4` episodes). Pairs with **`episodes >= 3`** are stored with `pages, episodes, same_side_reverted, same_side_reverting, kind_a, kind_b, first_episode_ts, last_episode_ts`.

4. **`research.s6_rev_author`** (`862,076` rows, PK `rev_id`) + **`features.py`**:
   - `corpus.revision`'s primary key is `(page_id, rev_id)` with no standalone `rev_id` index (`WHERE rev_id IN (...)` on `corpus.revision` scans `862k` index entries). `s6_rev_author` provides O(1) `rev_id -> (page_id, user)` lookup.
   - `features_for(rev_ids)` answers **`500` deterministic `rev_id`s in `4.5 ms` server-side (`0.41–0.54 s` end-to-end over the SSH tunnel)** (zero window functions, single `STRAIGHT_JOIN` PK-indexed query per 950 IDs, returning only `aot.user_display` and masked IP prefixes).

#### Which Features Carry the Lift — and Which Add False Positives?

1. **Features separating `dispute`/`edit_war` from `never_reverted` (substantive signal lift):**
   - **Leave-one-out `reverted_ratio` (`edits >= 2`):** **13.5× lift** among named humans (`0.2632` vs `0.0195`) and
     **10.6×** among anonymous/temporary editors (`0.7030` vs `0.0661`), showing prior/other-edit revert history
     strongly separates contested edits from kept edits even without seeing the target edit's fate.
   - **Topic/article concentration (`top_page_share`, `single_purpose`):** Named human `dispute`/`edit_war` edits have
     **2.83×** higher `top_page_share` (`0.3783` vs `0.1338`) and **2.73×** higher `single_purpose` share (`8.52%` vs
     `3.12%`).
   - **Account breadth & tenure (`log1p(edits)`, `lifespan_days`) + edit size (`median_abs_bytes_delta`):** Contested
     named edits come from less established accounts (`log1p(edits)` `4.73` vs `6.82`) making **3.2×** larger typical
     byte changes (`178 B` vs `55 B`), and **2.15×** higher `reverts_of_others_ratio` (`0.1057` vs `0.0491`, reflecting
     counter-reverting in disputes).

2. **Features separating `dispute`/`edit_war` from `graffiti_cleanup` (anti-vandalism precision lift):**
   - **`kind` + `reverts_of_others_ratio` + `log1p(edits)`:** `72.68%` named, **22.6×** `reverts_of_others_ratio`
     (`0.1560` vs `0.0069`), and multi-day tenure (`265` vs `4.3` active days).
   - **Even within anonymous/temporary edits (`6,044` `dispute/edit_war` vs `28,720` `graffiti_cleanup`), three features
     cleanly separate persistent anonymous claims from drive-by graffiti:**
     - **`custom_summary_usage`** (`0.3535` vs `0.2087`, **1.69×**) — whereas raw `summary_usage` is flat (`0.5771` vs
       `0.5677`) because section-edit `/* Header */` prefixes mask empty summaries! **Always prefer
       `custom_summary_usage` over raw `summary_usage` in P1.S9/S10.**
     - **`single_purpose`** (`16.83%` vs `7.69%`, **2.19×**).
     - **Moderate `median_abs_bytes_delta`** (`246 B` vs `848 B` — mass blanking/paste dumps inflate graffiti size).

3. **False-positive traps to guard against in P1.S9 / P1.S10:**
   - **Unconditioned `throwaway = 1` and raw `reverted_ratio` on `edits = 1`:** `65.39%` of all `throwaway = 1` edits are
     anonymous `graffiti_cleanup`, and for `edits = 1`, `reverted_ratio` (`1.0`) is tautological with S1 revert status.
     Pair `throwaway` with `kind = 'named'` or content classification, and use leave-one-out revert counts when training
     or tuning scorers on S1 candidates.
   - **Standalone `single_purpose = 1`:** Because **91.53%** of named `single_purpose` edits are kept by Wikipedia,
     `single_purpose` must only adjust confidence on already-reverted/contested claims, never flag edits on its own.
   - **Raw `coactivity_partners > 0`:** Nearly flat between named `dispute/edit_war` (`22.61%`) and `never_reverted`

## Caveats (Binding for Downstream Pipeline & UI)

1. **Corpus-only visibility (`19,742` History-of-Finland articles):** Every count, share, and lifespan in `s6_*` covers
   only Dataset M (`2003-02-21` to `2026-10-01` inside the Finnish history category tree). An editor with 10,000 edits
   on biology or music articles and 6 edits on one war article appears here with `edits = 6, top_page_share = 1.0,
   single_purpose = 1`. "Single-purpose" is therefore a corpus-local behavioural pattern, not a global statement about
   the account.
2. **Shared and reassigned IP addresses:** Schools, universities (`128.214.x.x`, `193.64.x.x`), municipal networks, and
   mobile CGNAT/IPv6 pools (`2001:14BA:…`, `85.76.x.x`) share `/24`, `/16`, and `/64` prefixes across many unrelated
   people, while one person may also rotate addresses. IP-prefix features are weak supporting context only — never proof
   of identity — and Level 3 editor counting collapses each masked `/16` or `/32` range into a single editor.
3. **Confidence adjustment only — never shown as accusations:** Per P0.7 (`docs/evidence-standard.md`), these features
   feed internal candidate ranking and confidence calibration (P1.S7, P1.S9, P1.S10) and **cannot promote an incident on
   their own** without a substantive claim check and community-dispute evidence. They are never surfaced as account
   scores, labels, or accusations against a person or account.
4. **Preventing target leakage in historical evaluation:** Full-corpus `reverted_ratio` and `throwaway` include every
   reverted edit in Dataset M. When evaluating a candidate scorer on historical S1 reverts, either use leave-one-out
   revert counts `(reverted_edits_by_others - this_edit_reverted) / (edits - 1)` for `edits >= 2` (`0.0` prior signal on
   `edits = 1`) or restrict `reverted_ratio` to other pages/timestamps so 1-edit reverts are not scored tautologically.
